\section{Parameter conventions}

The theory uses $\phi(t)=\kappa\theta e^{-\theta t}$ ($\kappa=$ branching ratio,
$\theta=$ decay); the event-time code uses $\phi(t)=\alpha e^{-\beta t}$. They match
via $\alpha=\kappa\theta$, $\beta=\theta$, i.e.\ $\kappa=\alpha/\beta$; convert with
\code{kappa\_theta\_to\_alpha\_beta} / \code{alpha\_beta\_to\_kappa\_theta}.
